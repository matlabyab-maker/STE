# STE — Simple Text Editor

Lightweight Android text and source-code editor starter.

## Emoji editing

The editor uses AndroidX Emoji2 1.6.0 and `EmojiEditText` to support EmojiCompat rendering while editing. Version 1.6.0 is selected to retain compatibility with minSdk 23. Actual glyph availability can still depend on the device's emoji font/provider and should be tested on the target device.
